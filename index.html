RetryClassifier

10 error classes.
10 specific recovery paths.

Not "retry with backoff." Specific: parse the Retry-After header. Switch model after 3 consecutive overloads. Never retry a validation error.

Error Class Status Recovery Action
Rate Limited 429 Parse Retry-After header → wait exact duration retry
Server Overload 529 / 503 Track consecutive count → switch model after 3 switch model
Context Overflow 400 Trigger ContextBudget compaction → retry compact + retry
Auth Failure 401 / 403 Clear cache → refresh token → retry once only refresh + retry
Network Error 0 / ECONNRESET Disable keep-alive → fresh connection → backoff retry
Quota Exceeded 429 + overage Permanently downgrade model → notify operator permanent switch
Streaming Stall timeout (no chunks) Abort stream → retry non-streaming request non-stream retry
Input Validation 422 Log error → return structured failure to model no retry
ContextBudget

Two-tier compaction.
Cheapest method first.

Tier 1 runs on every turn at zero cost — old tool results get cleared. Tier 2 only fires when Tier 1 isn't enough.

Tier Trigger Cost Method
Microcompact Every turn $0 Clear old tool results
Auto-compact Context > 80% ~$0.001 Summarize old turns

⚡ The Circuit Breaker

After 3 consecutive compactions that don't reduce context below threshold, the circuit trips. No more compaction. Prevents the infinite loop that cost real users hundreds of dollars before they noticed.

⚠ Next API call will fail
AFTER: ContextBudget applied

Setup in 5 Minutes

Import. Wire. Configure.

No dependencies. No accounts. No API keys. Just import a JSON file into n8n and connect it.

1

Import

Download the workflow JSON files and import them into your n8n instance.

n8n Settings
→ Import Workflow
→ Select JSON file
2

Wire

Add an Execute Workflow node in your agent workflow pointing to AgentGuard.

// After your HTTP call
[Execute Workflow]
→ RetryClassifier
3

Configure

Set your fallback model, context thresholds, and permission rules in the config object.

fallbackModel: 'gemma4:e4b'
compactionThreshold: 0.80
defaultAction: 'prompt'
